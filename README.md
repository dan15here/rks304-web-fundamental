# Web Fundamental

Repository ini digunakan untuk mengumpulkan tugas dan proyek mata kuliah **Web Fundamental** selama satu semester di **Politeknik Negeri Batam**.

## Struktur Repository

Setiap tugas disimpan dalam folder berdasarkan minggu perkuliahan:

```text
.
├── Minggu 1/
│   ├── index.html
│   ├── portfolio.html
│   ├── contact.html
│   ├── style.css
│   └── img/
├── Minggu 2/
├── Minggu 3/
└── ...
```

## Daftar Tugas

Daftar ini akan diperbarui seiring bertambahnya tugas.

## Teknologi

- HTML5
- CSS3
- JavaScript
- Git dan GitHub

Teknologi yang digunakan dapat berbeda pada setiap tugas sesuai materi perkuliahan.

## Menjalankan Tugas

Sebagian besar tugas dapat dijalankan langsung dengan membuka file `index.html` pada folder tugas.

Untuk menjalankan melalui local server:

```bash
python -m http.server 8000
```

Kemudian buka `http://localhost:8000/` dan pilih folder tugas yang ingin dijalankan.
